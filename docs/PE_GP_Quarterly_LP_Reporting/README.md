# PE / GP Quarterly LP Reporting Demo Package

This zip contains a corrected hypothetical Private Equity GP quarterly LP reporting scenario for Auquan.

## Contents
1. `01_Process` - process blueprint, stakeholder workflow, and process flow diagram.
2. `02_Source_Inputs` - hypothetical PDFs, XLSX workbooks, and email submissions used as source inputs.
3. `03_Final_Output` - final LP-facing quarterly report PDF.
4. `04_Audit_And_Lineage` - review/approval log and source lineage notes.

## Demo premise
Portfolio companies and fund service providers submit source materials. The GP ingests, normalizes, validates, and synthesizes the information into a controlled LP report that is reviewed by deal teams, fund accounting/CFO, valuation committee, investor relations, legal/compliance, and the Managing Partner before distribution.
